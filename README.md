### About the game:
Everyone knows Flappy Bird (I hope at least), so this is like you would expect since I just made it \
for fun and so that I do not have to install the game if I want to play it when I have my "own"

## Project structure
+ `project_root`
+ + `assets`
+ +  + `images`
+ +  +  `sounds`
+ +  +  `fonts`
+ + `CPLibrary`
+ + `external`
+ +  + `glad`
+ + `src`
+ + + `.h and .cpp files`
+ + + `main.cpp`      
+ + `CMakeLists.txt`

> [!IMPORTANT]
> In assets, all images (.png) and sounds (.mp3) will be stored.\
> In CPLibrary is my own framework and its code
> In external GLAD will be stored (the other dependencies will be installed per CMake)
> In the src file are all .h and .cpp files needed for the game including main.cpp

## Controls
Only controls you have is clicking/tapping that is already it.
